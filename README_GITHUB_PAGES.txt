TING MAX V45 — GitHub Pages ready

1. Sign in at https://github.com and create a PUBLIC repository named ting-max.
2. Open the repository > Add file > Upload files.
3. EXTRACT this ZIP first. Upload index.html, unstable-library.html, .nojekyll, and README_GITHUB_PAGES.txt directly to the repository ROOT (not inside a folder).
4. Commit changes.
5. Go to Settings > Pages > Build and deployment > Deploy from a branch.
6. Select main and / (root), then Save.
7. Visit https://YOUR-USERNAME.github.io/ting-max/ after deployment finishes.

Notes:
- The site uses relative links for the Unstable SMP library and embeds its Minecraft background in index.html.
- Embedded games and YouTube video/music players rely on third-party sites and may be blocked by those providers.
- Music with sound requires a user gesture before it can start; browsers prevent guaranteed autoplay.
- This ZIP contains static files only and needs no Node.js or Cloudflare Pages.
- Existing Cloudflare site will not be deleted by uploading this to GitHub Pages.
